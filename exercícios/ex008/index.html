Principais Formatações

Negrito / Destaque

Nesta frase temos um termo em negrito usando a tag B.

Nesta frase temos um termo em destaque usando a tag STRONG (semântica).

Itálico / Ênfase

Nesta frase temos um termo em itálico usando a tag I.

Nesta frase temos um termo em ênfase usando a tag EM (semântica).

Usando o comamdo CTRL + SHIFT + P, após selecionar uma frase, é possível acessar as abreviações que de deseja.

Texto Marcado

Podemos criar também um texto marcado usando a tag MARK.

E é possível inclusive mudar a cor da marcação usando o CSS

Texto grande e pequeno

Estamos criando um texto grande e um texto pequeno neste parágrafo.

Obs: A tag BIG que torna o texto grande é considerada obsoleta em HTML5.

Texto deletado

Podemos macar um texto como excluído para indicar que ele deve ser lido mas não considerado.

Texto inserido

Podemos marcar um texto como inserido para dar uma ênfase e indicar que ele foi adicionado depois.

Existe também o sublinhado com a tag U
